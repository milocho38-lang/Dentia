# Revisión clínica Periodontograma Dentia

**Código:** PERIO-0.1

**Fecha de preparación:** 2026-09-17

**Duración estimada:** 30–45 minutos

**Objetivo de la sesión:** obtener las decisiones clínicas mínimas para construir un periodontograma seguro y útil sin convertir la reunión en una revisión técnica.

## Cómo utilizar este documento

1. Revisar primero el flujo clínico de referencia.
2. Resolver las diez decisiones del Bloque A; son las únicas que bloquean el inicio de PERIO-1.
3. Si queda tiempo, revisar el Bloque B. Estas decisiones pueden cerrarse durante la construcción mediante prototipos.
4. El Bloque C no bloquea el MVP y puede resolverse en otra sesión.
5. Marcar una opción cuando corresponda y completar ejemplos o notas. Ninguna opción está preseleccionada.
6. Si la práctica del profesional no coincide con las opciones, usar “Otra” y describirla.

Este documento no busca diagnosticar ni establecer una guía clínica general. Busca reflejar cómo debe registrar información Dentia bajo validación profesional.

## Flujo que se presentará al profesional

```text
Paciente
  → Periodontograma
  → Nuevo examen
  → Confirmar dientes presentes, ausentes e implantes
  → Registrar mediciones y hallazgos
  → Revisar cobertura e índices
  → Finalizar
  → Consultar histórico
  → Crear nuevo control o copiar datos seleccionados del anterior
```
