## Privacidad y metadatos

- No se observaron correos o teléfonos reales, URLs con tokens, OTP, credenciales, cookies, nombres de clientes fundadores ni datos de otros tenants.
- Todos los nombres, documentos, teléfonos y eventos visibles pertenecen al dataset sintético Aurora.
- Las fuentes v2 y v4 contienen únicamente resolución, perfil Display P3 y el comentario XMP genérico `Screenshot`; no se encontraron autores, ubicaciones ni comentarios privados.
- Las seis capturas aprobadas en WEB-2D permanecen byte a byte idénticas a sus fuentes.
- No se aplicó blur ni se ocultó silenciosamente información.
